# 数据与参数

`data/` 保存项目数据字典以及气动、电池、逆变器、电机、轮胎和赛道数据。模型、仿真和验证代码应从这里读取参数，不在脚本中复制维护第二份物理参数。

## 数据入口

| 位置 | 内容 |
|---|---|
| `VehicleData.sldd` | 整车共享参数、Variant 和 Bus 相关数据 |
| `AeroMaps/` | 气动特性数据 |
| `BatteryMaps/` | 电池包参数与特性图 |
| `InverterMaps/` | 逆变器效率和限制数据 |
| `MotorMaps/` | 电机效率、转矩和转速数据 |
| `TireData/` | TTC、MF6.2 和轮胎拟合数据 |
| `TrackData/` | 赛道源数据与提取说明 |

## 参数维护

- 参数字段、单位、来源、可信度和待确认状态见 [参数来源](ParameterSources.md)。
- 赛道图片来源、校验值和提取假设见 [赛道数据](TrackData/README.md)。
- 未确认参数必须保留为明确占位，不得描述为实测或已标定值。
- 修改参数后应运行受影响组件、Plant 和闭环场景的对应测试。

项目初始化、数据字典编辑示例和模型切换方法见 [模型使用说明](../models/README.md)。
