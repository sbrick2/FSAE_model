# FSAE 坐标系、单位与符号约定

> 状态：ProjectFoundation 冻结版
> 更新日期：2026-07-24
> 适用范围：全部 MATLAB、Simulink、轮胎数据、赛道数据、测试与报告

## 1. 基本原则

- 内部计算统一使用 SI 单位；
- 角度内部统一使用 `rad`，角速度使用 `rad/s`；
- 四轮数组顺序固定为 `[FL, FR, RL, RR]`；
- 所有坐标转换必须集中实现并有单元测试；
- TTC、CAD、CFD、传感器或赛道数据进入模型前必须显式转换；
- 未经接口变更评审，不得改变本文件的坐标系或符号。

## 2. 全局坐标系 G

采用右手笛卡尔坐标系：

| 量 | 正方向 | 单位 |
|---|---|---|
| `X_G` | 全局地图定义的前向/东向轴 | m |
| `Y_G` | 与 `X_G` 构成右手平面的左向/北向轴 | m |
| `Z_G` | 垂直向上 | m |
| `Psi` | 绕 `+Z_G`，从 `+X_G` 转向 `+Y_G` | rad |

赛道文件必须同时记录其坐标原点、轴方向、投影方式和单位；导入后统一转换到 G 系。

## 3. 车身坐标系 B

原点位于整车质心，采用右手系：

| 轴/量 | 正方向 | 备注 |
|---|---|---|
| `+x_B` | 车辆前方 | 纵向速度 `Ux > 0` 表示前进 |
| `+y_B` | 车辆左方 | 横向速度 `Uy > 0` 表示质心向左运动 |
| `+z_B` | 车辆上方 | 垂向位移向上为正 |
| `YawRate = r` | 绕 `+z_B` | 左转为正 |
| `RollAngle = phi` | 绕 `+x_B` | 左侧车身上抬、右侧下沉为正 |
| `PitchAngle = theta` | 绕 `+y_B` | 按右手定则，车头下俯为正 |

车身到全局平面的速度变换：

```text
Xdot = Ux*cos(Psi) - Uy*sin(Psi)
Ydot = Ux*sin(Psi) + Uy*cos(Psi)
Psidot = YawRate
```

## 4. 车轮顺序与位置

固定四轮索引：

| 索引 | 名称 | 车身坐标位置 |
|---:|---|---|
| 1 | `FL` | 前轴、左侧：`x > 0, y > 0` |
| 2 | `FR` | 前轴、右侧：`x > 0, y < 0` |
| 3 | `RL` | 后轴、左侧：`x < 0, y > 0` |
| 4 | `RR` | 后轴、右侧：`x < 0, y < 0` |

所有长度为 4 的向量、查表输出、日志列和图例必须遵守该顺序。

## 5. 车轮局部坐标系 W

每个车轮使用局部右手坐标系：

- `+x_W`：车轮平面内的滚动前方；
- `+y_W`：车轮平面内的左方；
- `+z_W`：向上；
- 转向角 `delta > 0`：车轮朝车辆左侧转动；
- 轮速 `omega > 0`：车辆前进时的滚动方向；
- 驱动转矩 `T_drive > 0`：增加正轮速；
- 摩擦制动转矩采用非负幅值，并在动力学方程中始终反向于轮速。

## 6. 轮胎滑移与力

### 6.1 纵向滑移率

正常速度区采用：

```text
kappa = (Re*omega - Vx_wheel) / max(abs(Vx_wheel), VxEpsilon)
```

- `kappa > 0`：驱动滑移；
- `kappa < 0`：制动滑移；
- `Re`：有效滚动半径；
- `VxEpsilon`：低速保护参数，不得硬编码；
- 零速附近必须使用连续过渡或状态逻辑，ProjectFoundation 只冻结符号，不冻结最终正则化算法。

### 6.2 侧偏角

车轮局部接地点速度为 `(Vx_wheel, Vy_wheel)`，定义：

```text
alpha = atan2(Vy_wheel, regularized(Vx_wheel))
```

- `alpha > 0`：接地点速度相对车轮指向左侧；
- 线性区轮胎横向力满足 `Fy_wheel ≈ -C_alpha*alpha`；
- 低速正则化必须连续并单独测试。

### 6.3 外倾角

`CamberAngle = gamma > 0` 表示轮胎顶部向车辆外侧倾斜。左右轮均按“相对车辆外侧”定义，导入 TTC 数据时必须逐侧确认符号并记录转换。

### 6.4 轮胎力

| 量 | 正方向 |
|---|---|
| `TireFx` | 沿 `+x_W` |
| `TireFy` | 沿 `+y_W` |
| `NormalLoad` | 路面对轮胎的法向支持力幅值，向上为正且正常工况非负 |
| `AligningMoment` | 绕 `+z_W`，按右手定则 |

轮胎力从 W 系旋转到 B 系后再进入整车力和力矩平衡。

### 6.5 TireModel TTC 数据映射

- TTC SI MAT 文件采用 SAE 通道；项目取 `NormalLoad=-FZ`，保证法向载荷幅值为正；
- 项目纵向滑移率使用 TTC `SL`，不使用试验机控制通道 `SR`；
- `SlipAngle=deg2rad(SA)`，`TireFy=FY`；目标数据在零侧偏附近满足 `dFY/dSA<0`，与项目 `Fy≈-C_alpha*alpha` 一致；
- 43075 小外径轮胎使用偏置适配器，`N/RE` 不能代表有效滚动半径；TireModel 清洗保留 `RL`，并将异常 `RE` 作为显式警告；
- 43075 没有可传递驱动转矩的 drive/brake 数据，纵向和联合滑移只允许使用报告中明确标记的同配方代理。

## 7. 转矩、功率和制动符号

| 量 | 正值含义 |
|---|---|
| `MotorTorqueRequest[i]` | 驱动该车轮前进；负值表示电机再生制动 |
| `FrictionBrakeTorqueRequest[i]` | 非负制动幅值；实际作用方向与轮速相反 |
| `RegenTorqueRequest[i]` | 非负再生制动需求幅值，仅作分配信息；Plant 不得与最终电机转矩重复叠加 |
| `BatteryPower` | 电池向直流母线放电为正，充电/回收为负 |
| `MechanicalPower[i]` | 电机向车轮输出机械功为正，回收为负 |
| `DriveTorqueRequest` | 驾驶员总驱动需求为正 |
| `BrakePressureRequest` | 非负液压制动需求 |

## 8. 气动力与环境量

- `WindVelocityGlobal` 表示空气相对地面的全局速度；
- 相对气流由车辆速度减去风速得到；
- `DragForce` 以阻力幅值记录，作用方向与相对纵向运动相反；
- `FrontDownforce`、`RearDownforce` 使用非负向下幅值；
- `AeroSideForce` 使用车身 `+y_B` 为正；
- `AeroYawMoment` 使用左转为正。

## 9. 赛道与路径误差

- 赛道弧长 `s` 沿行驶方向递增；
- 曲率 `kappa_path > 0` 表示左弯；
- 横向误差 `LateralError > 0` 表示车辆质心位于参考线左侧；
- 航向误差 `HeadingError = Psi - ReferenceHeading`，左偏为正；
- 左、右赛道半宽均用非负值存储。
